# Automated Inventory Control System

This is a full-stack automated inventory management system designed to track stock, manage products, and record stock movements efficiently.
Made for a school project.

---

## Features

- Product management (add/update/delete)
- Stock tracking system
- Stock movement history
- User management system
- RESTful backend API
- Database migrations (Alembic)

---

## Tech Stack

**Backend:**
- Python
- Flask (or FastAPI depending on yours)
- SQLAlchemy
- Alembic migrations

**Frontend:**
- React (UI library for building interactive user interfaces)
- JavaScript (core frontend logic)
- HTML5 (page structure)
- CSS3 (styling and layout)
- Axios / Fetch API (for backend communication)
- React Router (for navigation between pages)
- State Management (useState / useContext)

**Database:**
- SQLite / MySQL / PostgreSQL
